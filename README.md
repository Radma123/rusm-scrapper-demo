# Rusmarket Scraper & AI Filter

Модульный и расширяемый конвейер для веб-скрапинга и фильтрации данных, написанный на Python с использованием FastAPI и Camoufox. Проект собирает товары с различных маркетплейсов, очищает данные, применяет умную фильтрацию с помощью искусственного интеллекта (локальная ML Transformer модель или OpenAI) и возвращает готовые результаты.

Стек:
- Python
- FastAPI
- SCSS
- uvicorn

## 🚀 Особенности

- **Мульти-скрапинг**: Из коробки поддерживается парсинг 4 источников
- **AI Фильтрация и Обработка**: Возможность выбора между локальной ML Transformer моделью или API OpenAI для анализа, фильтрации и оценки найденных товаров на основе запроса пользователя.
- **Интеграция Camoufox**: Продвинутый headless-браузер для скрапинга, позволяющий обходить анти-бот защиты.
- **Динамическая компиляция SCSS**: Автоматическая компиляция SCSS в CSS при запуске для быстрой и удобной работы со стилями.
- **Чистая архитектура**: Спроектировано с использованием принципов SOLID и классических паттернов проектирования для максимальной расширяемости.
- **Асинхронность и конкурентность**: Использование `ThreadPoolExecutor` для многопоточного сбора данных с нескольких скраперов.

## 🏗 Архитектура и паттерны проектирования

Проект следует подходу чистой архитектуры, активно используя паттерны ООП для обеспечения поддерживаемости и масштабируемости.

### 1. Паттерн Стратегия (Strategy)
Все скраперы реализуют общий интерфейс, определенный в `BaseScraper` или `BaseBrowserScraper`. Это позволяет основному сервису `SearchService` работать с любым количеством скраперов, не зная деталей их внутренней реализации. Чтобы добавить новый источник, достаточно создать новый класс, унаследованный от `BaseScraper`, и реализовать в нем метод `scrape()`.

### 2. Паттерн Конвейер (Pipeline)
После сбора данных они проходят через последовательный конвейер обработки в `services/pipeline.py`:
1. **PriceSanitizer**: Очищает строки с ценами, преобразуя их в единый числовой формат.
2. **PhotoNormalizer**: Проверяет ссылки на изображения и делает их абсолютными.
3. **AIFiltrator**: Пропускает данные через выбранную AI-модель для фильтрации нерелевантных товаров и присвоения им оценки релевантности (score).
4. **PriceSorter**: Сортирует итоговый список по цене или релевантности.

### 3. Внедрение зависимостей (Dependency Injection)
Модули слабо связаны друг с другом. Сервис `SearchService` получает свои зависимости (список скраперов и объект AI-фильтра) через конструктор (`__init__`). Эта конфигурация централизованно задается в `main.py`, что позволяет невероятно легко менять реализацию AI (например, переключаться с OpenAI на Transformer) или внедрять mock-объекты при тестировании.

### 4. Паттерн Фасад (Facade)
Директория `models/` выступает в роли фасада. С помощью файла `models/__init__.py` сложные внутренние структуры данных (`Item`, `SearchQuery`) экспортируются "наружу" чисто, позволяя другим модулям импортировать их простым `from models import Item`.

## 🛠 Структура файлов

```text
rusm-scrapper-demo/
├── api/                   # Эндпоинты маршрутизации FastAPI
├── models/                # Pydantic модели (Item, ItemList, фильтры)
├── scrappers/             # Реализации скраперов
│   ├── base.py            # Базовые интерфейсы (BaseScraper, BaseBrowserScraper)
│   ├── avito.py           # Стратегия скрапинга Avito
│   └── ...                # Другие скраперы (Ozon, Autopiter и т.д.)
├── services/              # Основная бизнес-логика
│   ├── search.py          # SearchService (Оркестратор сбора)
│   └── pipeline.py        # Шаги конвейера постобработки
├── tools/
│   └── ai_filter/         # Модуль AI фильтрации
│       ├── filter.py      # Абстрактный класс BaseFilter
│       ├── openai_filter.py
│       └── transformer_filter.py
├── static/                # Статические файлы (скомпилированный CSS, JS)
├── templates/             # HTML шаблоны
├── tests/                 # Модульные и интеграционные тесты
├── .env.example           # Пример конфигурационных переменных
├── config.py              # Централизованный конфиг через pydantic-settings
└── main.py                # Точка входа в приложение и DI-контейнер
```

## ⚙️ Установка и запуск

1. **Склонируйте репозиторий** и перейдите в папку проекта.
2. **Создайте виртуальное окружение**:
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # На Windows: .venv\Scripts\activate
   ```
3. **Установите зависимости**:
   ```bash
   pip install -r requirements.txt
   ```
4. **Настройте переменные окружения**:
   Скопируйте пример файла конфигурации и заполните ваши чувствительные данные:
   ```bash
   cp .env.example .env
   ```
   *Отредактируйте `.env`, указав ваш `OPENAI_API_KEY`, режим `AI_FILTER_MODE` (например, `openai` или `transformer`), и другие настройки.*

## 💻 Использование

### Запуск приложения

Вы можете использовать предоставленные скрипты для запуска сервера:

- **Linux / macOS**:
  ```bash
  ./run.sh
  ```
- **Windows**:
  ```cmd
  run.bat
  ```

*(При запуске сервер автоматически скомпилирует SCSS в CSS и запустит FastAPI сервер на порту 8000).*

### Запуск тестов

Для выполнения набора тестов (unit и интеграционных):
```bash
python3 -m unittest discover tests
```

## 🧩 Расширение проекта

### Добавление нового скрапера
1. Создайте новый файл в папке `scrappers/`.
2. Унаследуйтесь от `BaseScraper` (или от `BaseBrowserScraper`, если нужен Camoufox).
3. Реализуйте метод `scrape(query)`, который должен возвращать список объектов `Item`.
4. Зарегистрируйте ваш новый экземпляр скрапера в списке `scrapers` в файле `main.py`.

### Добавление нового AI-фильтра
1. Создайте новый класс фильтра в папке `tools/ai_filter/`, унаследовавшись от `BaseFilter`.
2. Реализуйте метод `filter_items(items, query)`.
3. Добавьте его логику инициализации в фабрику внутри `main.py` (или `config.py`) в зависимости от настроек в `.env`.
